# House 3D Viewer

Minimal public web viewer for an interactive house model.

## Features

- Three.js orbit / pan / zoom
- Whole-house and per-floor views
- Ceiling toggle for dollhouse-style viewing
- Responsive desktop/mobile interface
- GitHub Pages deployment

## Model

The public model asset is expected at:

`public/models/house-existing.glb.dat`

The file contains ordinary GLB bytes; `.dat` is only the public filename extension.

## Local development

```bash
npm install
npm run dev
```
